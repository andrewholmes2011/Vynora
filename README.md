# Vynora

**Your sound. Your universe.**

Vynora is a custom music-player concept with an original purple-and-gold interface, browsing by mood/genre, search, likes, shuffle/repeat, a playback bar, and local audio import.

## Run it

This first version is a static browser prototype:

1. Open `index.html` in a modern browser, or publish the repository with GitHub Pages.
2. Select **Import music**.
3. Choose audio files you own or are licensed to use.
4. Select a track to play it. Use the bottom player to pause, skip, seek, adjust volume, shuffle, repeat, or like a track.

## Current limitations

- Imported audio is played locally in the current browser session. Refreshing or closing the page clears the imported tracks.
- Music is not uploaded or shared between accounts/devices.
- There is no account system, online song catalog, streaming backend, cloud storage, or native phone/TV app in this prototype.
- Genre browsing is a UI foundation; imported tracks are initially labelled **Other**.

## Next development steps

Only upload and distribute music you own or have permission to use. Vynora is an independent project and is not affiliated with Spotify.
